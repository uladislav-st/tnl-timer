# Nix Tracker

Локальный Windows-помощник для **Throne and Liberty (Amazon Games / Steam, регион EU)**: таймеры прохождений, расписание боссов, погода и цикл дня/ночи.

[![Windows build](https://github.com/uladislav-st/tnl-timer/actions/workflows/release.yml/badge.svg)](https://github.com/uladislav-st/tnl-timer/actions/workflows/release.yml)

## Скачать

Откройте [последний релиз](https://github.com/uladislav-st/tnl-timer/releases/latest) и выберите один из вариантов:

- `Nix-Tracker-Setup-<version>-x64.exe` — рекомендуемая установка с автоматическими обновлениями;
- `Nix-Tracker-Portable-<version>-x64.exe` — запуск без установки, обновляется вручную.

Сборка пока не подписана коммерческим сертификатом, поэтому Windows SmartScreen может показать предупреждение при первом запуске.

## Возможности

- пользовательские таймеры данжей и активностей с кнопкой «Пройдено»;
- системные уведомления перед окончанием кулдауна;
- автоматическое расписание T4-боссов Amazon/Steam EU, включая Porfos и Thuban;
- фиксированный список только боссов с внутренней прокруткой;
- добавление собственных боссов из игрового Timetable;
- прогноз дождя для Laslan/Stonegard и Talandre;
- цикл дня и ночи, московское время и история прохождений;
- компактный режим и закрепление окна поверх игры;
- встроенная проверка обновлений через GitHub Releases.

## Автоматические обновления

Установленная `Setup`-версия проверяет GitHub Releases через несколько секунд после запуска и затем каждые шесть часов. Новая версия загружается в фоне; после загрузки кнопка версии предлагает установить обновление и перезапустить приложение.

Версии `1.2.1` и старше ещё не содержат обновлятор — их нужно один раз вручную заменить на `1.3.0` или новее. Portable-версия по нажатию на индикатор открывает страницу релизов.

## Безопасность

Приложение не внедряется в игровой клиент, не читает память игры, не перехватывает игровой трафик и не отправляет команды. Оно работает как отдельное окно и обращается в интернет только за публичным расписанием и обновлениями. Пользовательские таймеры и история сохраняются локально на компьютере.

## Запуск из исходников

Требуется Node.js 22 или новее.

```powershell
npm ci
npm start
```

Сборка Windows-версий:

```powershell
npm run dist
```

Готовые файлы появятся в каталоге `release`.

## Публикация новой версии

Перед обновлением увеличьте версию и отправьте изменения в `main`:

```powershell
npm version patch --no-git-tag-version
git add .
git commit -m "Release new version"
git push origin main
```

GitHub Actions запускает тесты, создаёт тег, собирает обе Windows-версии, загружает все файлы в черновик Release и публикует его только после успешной загрузки `latest.yml` и установщика.

## Источники расписания

В приложение встроена резервная EU T4-ротация. При запуске календарь обновляется из публичных данных [Throne Watch](https://thronewatch.app/); расписание также можно сверять с [Questlog](https://questlog.gg/throne-and-liberty/en). Всё время автоматически показывается для часового пояса `Europe/Moscow`.
