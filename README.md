# Nix Tracker

Локальный таймер активностей и событий для Throne and Liberty: Nix.

![Интерфейс Nix Tracker](ui-preview.png)

## Возможности

- пользовательские кулдауны с кнопкой «Пройдено»;
- системные уведомления;
- редактируемое расписание боссов и событий;
- автоматическая EU-ротация T4-боссов Amazon/Steam, включая Porfos и Thuban;
- фиксированный прокручиваемый список только боссов без общих событий;
- автоматический прогноз дождя и цикла день/ночь;
- история прохождений;
- компактный режим и окно поверх игры;
- автоматическая проверка обновлений через GitHub Releases;
- локальное хранение данных без подключения к игровому клиенту.

## Запуск

```powershell
npm install
npm start
```

## Windows-сборка

```powershell
npm run dist
```

Готовые файлы появятся в папке `release`.

- `Nix-Tracker-Setup-<version>-x64.exe` — установщик;
- `Nix-Tracker-Portable-<version>-x64.exe` — запуск без установки.

Автообновление работает в установленной `Setup`-версии. Portable-сборка при нажатии на индикатор версии открывает страницу GitHub Releases для ручного обновления.

## Публикация обновления

Перед каждым обновлением увеличьте версию и отправьте изменения в ветку `main`:

```powershell
npm version patch --no-git-tag-version
git add .
git commit -m "Release new version"
git push origin main
```

GitHub Actions запустит тесты, соберёт установщик и portable-файл, создаст публичный Release и добавит служебный `latest.yml`. Установленные копии проверяют обновления при запуске и затем каждые шесть часов. Если версия из `package.json` уже опубликована, workflow остановится, чтобы случайно не перезаписать релиз.

Удаление активности или события доступно в форме редактирования по кнопке `•••`.

Приложение не читает память игры, не перехватывает сетевой трафик и не отправляет игровые команды.

## Данные расписания

Автоматический календарь предназначен для Amazon/Steam EU. В приложение встроена резервная T4-ротация, а при запуске оно обновляет расписание из публичного JSON-календаря Throne Watch. Погодные циклы проверены 7 сентября 2026 года по Questlog; появление Porfos и Thuban подтверждено официальными сообщениями Amazon Games.
